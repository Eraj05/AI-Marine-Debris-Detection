# Project Workflow

## Input

The user uploads an underwater image through the prototype.

## Step 1 - Image Processing

The uploaded image is converted into a suitable format for analysis.

## Step 2 - AI Analysis

Computer vision techniques are used to analyze the underwater scene.

## Step 3 - Marine Debris Detection

A future validated object-detection model can identify visible marine debris such as:

- Plastic bottles
- Plastic bags
- Fishing nets
- Cans
- Other marine waste

## Step 4 - Environmental Analysis

The system can generate useful information about the detected debris and underwater scene.

## Step 5 - Monitoring Report

The results can be presented as a simple environmental monitoring report.

## Complete Pipeline

Underwater Image
↓
Image Processing
↓
AI Analysis
↓
Marine Debris Detection
↓
Classification
↓
Environmental Analysis
↓
Monitoring Report
