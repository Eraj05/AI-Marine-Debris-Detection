# Dataset Plan

## Purpose

A suitable underwater marine debris dataset is required to train and evaluate an object-detection model.

## Potential Classes

The planned detection categories include:

- Plastic Bottle
- Plastic Bag
- Fishing Net
- Can
- Other Marine Debris

## Dataset Requirements

The dataset should contain diverse underwater images with different:

- Lighting conditions
- Water visibility
- Object sizes
- Camera angles
- Background environments

## Data Preparation

The images should be:

1. Collected from appropriate sources
2. Cleaned and reviewed
3. Annotated with bounding boxes
4. Split into training, validation, and testing sets
5. Evaluated using suitable object-detection metrics

## Important Note

The current repository describes the prototype and model-development plan. Model accuracy should only be reported after actual training and evaluation.
